# Эскейп-квест «Колобок»

Индивидуальный проект по информатике, выполнен в 10 классе в 2023 году.

Игра в жанре эскейп-квест по мотивам русской народной сказки «Колобок».

Колобок заперт в избушке. Чтобы выбраться, необходимо разгадать загадки, собрать ингредиенты для торта и получить код от двери.

## Установка

Требуется Python 3.10+ и библиотека pygame:

```bash
pip install pygame
```

## Запуск

```bash
python main.py
```

## Управление

| Клавиша  | Действие                          |
|----------|-----------------------------------|
| `W`/`↑`  | движение вверх                    |
| `S`/`↓`  | движение вниз                     |
| `A`/`←`  | движение влево                    |
| `D`/`→`  | движение вправо                   |
| `E`      | диалог с персонажем / взаимодействие с предметом |
| `I`      | инвентарь                         |
| `Esc`    | скрыть текст                      |
