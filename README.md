# Эскейп-квест «Колобок»

[![CI](https://github.com/Iseyne/game-kolobok/actions/workflows/ci.yml/badge.svg)](https://github.com/Iseyne/game-kolobok/actions/workflows/ci.yml)

Индивидуальный проект по информатике, выполнен в 10 классе в 2023 году.

## О проекте

Игра в жанре эскейп-квест по мотивам русской народной сказки «Колобок».

Колобок заперт в избушке. Чтобы выбраться, нужно разгадать загадки, собрать ингредиенты для торта и получить код от двери. Игра написана на Python с использованием библиотеки pygame.

## Возможности

- Управление Колобком по комнате (клавиатура или стрелки)
- Четыре персонажа с квестами: медведь, волк, заяц и лиса
- Девять заданий: сейф, шкаф, записка, печь, холодильник, картина, стол и выход
- Система инвентаря и логика окончания игры
- Спрайты и фон, нарисованные в Inkscape

## Требования

- Python 3.10+
- Библиотека pygame

## Установка

Для запуска игры:

```bash
pip install -r requirements.txt
```

Чтобы запускать тесты, нужны дополнительные зависимости:

```bash
pip install -r requirements-dev.txt
```

## Запуск

```bash
python main.py
```

## Тесты

```bash
pytest
```

Тесты работают без графического окна (используется SDL dummy driver) и автоматически запускаются в GitHub Actions при каждом push и pull request.

## Управление

| Клавиша  | Действие                          |
|----------|-----------------------------------|
| `W`/`↑`  | движение вверх                    |
| `S`/`↓`  | движение вниз                     |
| `A`/`←`  | движение влево                    |
| `D`/`→`  | движение вправо                   |
| `E`      | диалог с персонажем / взаимодействие с предметом |
| `I`      | инвентарь                         |
| `Esc`    | скрыть текст                      |

## Структура проекта

```
app.py            — игровой цикл и обработка событий
main.py           — точка входа в игру
config.py         — настройки игры: NPC, мебель, стены
quest.py          — логика квестов персонажей
tasks.py          — описание заданий
task_base.py      — базовый класс задания и чистая логика evaluate
character.py      — персонажи
furniture.py      — интерактивные предметы
walls.py          — стены
kolobok.py        — игрок
sprites/          — изображения
tests/            — юнит-тесты
.github/          — конфигурация GitHub Actions
```
